# 0001 — Rust

Status: accepted · 2026-09-05

## Context
The tool must ship as one static binary, start in milliseconds, hold long-lived
watches and log streams, and later drive a terminal UI. The author is using the
project to learn Rust with a reference implementation (flowrs, a ratatui TUI for
Airflow) to borrow layering from.

## Decision
Rust, stable toolchain pinned in `rust-toolchain.toml`. `clap` for the CLI,
`kube-rs` for Kubernetes, `ratatui` for the TUI.

## Consequences
Longer compile times and a steeper start than Python or Go. In return: no runtime,
a single artefact for Homebrew/`cargo install`, and the type system carries the
domain model (ADR 0002).
